# Game sounds

Drop real samples here and they replace the built-in synthesized sound of the same name:

- `common/<name>.mp3`
- `slot/<name>.mp3` (Dragon Spire)
- `color/<name>.mp3` (Color Game)

The full list of names, lengths and generation prompts is in `docs/game-sounds.md`.
`manifest.json` is rebuilt automatically before every build; don't edit it by hand.
